# KISKIPAK_1 – Ötös számú vágóhíd

Az O épület (Pannon Egyetem, felső campus, Veszprém) egyetemi hubbá alakításának egyetemi projektoldala: helyszínelemzés,
műszaki dokumentáció, kulturális élet, célcsoport és funkcionális program. A felület magyar, angol nyelvváltással.

University project site on converting Building O (University of Pannonia, upper campus, Veszprém) into a university hub:
site study, technical documentation, cultural life, target group and functional programme. Hungarian, with an English toggle.

- Live: https://szeki02.github.io/kiskipak-1/ · also on claude.ai: https://claude.ai/artifact/CPGcu4PWuMT1voiNQxuPrB
- Static site: `index.html`, `css/`, `js/` (three.js 0.160 from jsDelivr), `data/`, `assets/`. Open it through any web server
  (the 3D model and data are fetched, so `file://` won't work).
- Sources and data credits are listed on the page (OpenStreetMap contributors, KSH, VeszprémGO, AWS Terrain Tiles, Meta/WRI canopy map, Esri imagery).
